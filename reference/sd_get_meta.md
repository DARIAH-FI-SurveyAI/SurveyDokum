# Get the metadata from an `sd_data` object

Get the metadata from an `sd_data` object

## Usage

``` r
sd_get_meta(x)
```

## Arguments

- x:

  An `sd_data` object, as created by
  [`sd_read()`](https://dariah-fi-surveyai.github.io/SurveyDokum/reference/sd_read.md).

## Value

A list. See
[`new_sd_data()`](https://dariah-fi-surveyai.github.io/SurveyDokum/reference/new_sd_data.md)
for the expected structure.
