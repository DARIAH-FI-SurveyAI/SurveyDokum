# Survey-aineisto: Tyytyväisyys palveluun

Hankkeen pääaineisto. Sisältää vastaajien taustatiedot ja
tyytyväisyysmittaukset.

## Usage

``` r
aineisto
```

## Format

Dataframe, jossa 5 riviä ja 4 muuttujaa:

- id:

  Vastaajan tunniste

- ika:

  Vastaajan ikä vuosina

- sukupuoli:

  Vastaajan sukupuoli (1 = Mies, 2 = Nainen)

- kysymys1:

  Tyytyväisyys palveluun, asteikko 1-5

## Source

Hankkeen sisäinen aineisto
